## 🧠 Overview

DaVinci Resolve is a Windows post-production application that keeps editing, color correction, visual effects, motion graphics and audio mixing inside one project database. A single timeline can move between pages without exporting: cuts and trims are made on the Edit page, grades and node trees on the Color page, composites and tracking on Fusion, and dialogue, music and effects on the Fairlight page.

The application works with proxy media, timeline resolution independent of source resolution, and a node-based color pipeline with qualifiers, power windows and tracking data. Depending on the project, users work with HDR grading, ACES color management, multicam editing, fairlight audio buses or Fusion compositions rendered back to the timeline as clips.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎬 Timeline Editing | Cuts, trims and arranges clips on a magnetic or standard timeline with ripple, roll and slip controls. |
| 🎨 Node-Based Grading | Builds color grades as node trees with qualifiers, power windows, curves and tracking data. |
| 🧩 Fusion Compositing | Composites layers, masks and 3D elements with a node graph and renders results back to the timeline. |
| 🔊 Fairlight Audio | Mixes dialogue, music and effects with buses, EQ, dynamics and loudness metering. |
| 📈 Scopes & Monitoring | Reads waveform, parade, vectorscope and histogram scopes for exposure and saturation control. |
| 🖥️ Multicam Editing | Syncs multiple camera angles and switches between them on a multicam timeline. |
| 🎞️ HDR & Color Management | Handles HDR grading, wide-gamut timelines and ACES color-managed workflows. |
| ⚡ Proxy Workflow | Generates and switches proxy media so editing stays responsive on large source files. |
| 📦 Delivery Presets | Exports to H.264, H.265, ProRes, DNxHR and image sequences with per-platform presets. |
| 🚀 Project Database | Keeps projects, timelines and media pool in a local or shared database with backup copies. |

## Additional Information for Windows Users

Resolve keeps render cache, optimized media and proxies on disk, so project responsiveness depends on storage speed and cache settings rather than on the CPU alone. Long timelines with node-heavy grades and Fusion compositions benefit most from a dedicated scratch disk and additional VRAM.

Export settings follow the delivery target: platform presets, color tags and audio loudness targets differ between broadcast, web and archive output, so delivery presets are usually kept per client instead of being edited globally for every render.
